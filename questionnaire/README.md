# پرسشنامه رکسانا

صفحهٔ مستقل پرسشنامه در `/questionnaire/` (یا `/questionnaire/index.html`) است. صفحهٔ اصلی، فایل ورودی و استایل‌های آن تغییری نکرده‌اند.

- اجرای محلی: `npm run dev`، سپس باز کردن `/questionnaire/`.
- خروجی انتشار: `npm run build`؛ پوشهٔ `dist/questionnaire` همراه با بقیهٔ `dist` روی هاست قرار بگیرد. روی IIS آدرس دارای اسلش آخر یا `index.html` نیاز به بازنویسی مسیر ندارد.
- آزمون‌ها: `node --test tests/questionnaire.test.js`.

پاسخ‌ها با قالب `?: سؤال-> پاسخ` مستقیم از مرورگر و با همان تنظیمات `BALE_BOT_TOKEN`، `BALE_CHAT_ID` و `BALE_CHAT_ID2` فرم BMI ارسال می‌شوند. پاسخ‌های طولانی در چند پیام مرتب با شناسهٔ مشترک می‌آیند. عکس‌های اختیاری با `sendPhoto` ارسال می‌شوند؛ هر عکس JPG یا PNG و حداکثر ۵ مگابایت است.

همانند فرم BMI، درخواست‌ها `no-cors` هستند؛ پاسخ بله از مرورگر قابل بررسی نیست. صفحه بین پایان درخواست‌ها و تأیید دریافت قطعی تفاوت می‌گذارد و در وضعیت نامشخص خودکار دوباره ارسال نمی‌کند. تنظیمات بله طبق روش موجود در JavaScript خروجی حضور دارند. هیچ‌کدام از آزمون‌ها پیام واقعی به بله نمی‌فرستند.

در Vercel فقط مسیر پرسشنامه اجازهٔ اتصال به بله و پیش‌نمایش `blob:` عکس‌ها را دارد؛ سیاست صفحهٔ اصلی همان مقدار قبلی است.
