# پرسشنامه رکسانا

صفحهٔ مستقل پرسشنامه در `/questionnaire/` (یا `/questionnaire/index.html`) است. صفحهٔ اصلی، فایل ورودی و استایل‌های آن تغییری نکرده‌اند.

- اجرای محلی: `npm run dev`، سپس باز کردن `/questionnaire/`.
- خروجی انتشار: `npm run build`؛ پوشهٔ `dist/questionnaire` همراه با بقیهٔ `dist` روی هاست قرار بگیرد. روی IIS آدرس دارای اسلش آخر یا `index.html` نیاز به بازنویسی مسیر ندارد.
- آزمون‌ها: `node --test tests/questionnaire.test.js`.

اطلاعات دقیق بخش آشنایی همچنان ورودی متنی یا عددی دارد. همهٔ سؤال‌های بخش‌های هدف و سلامت، تمرین و تغذیه گزینه‌ای هستند. چک‌باکس‌ها چندانتخابی و رادیوباتن‌ها تک‌انتخابی‌اند؛ تعداد انتخاب‌های چندتایی سقف جداگانه ندارد. پاسخ‌های «ندارم» و مشابه آن با سایر انتخاب‌های همان سؤال هم‌زمان ثبت نمی‌شوند.

برای شغل و تحرک، مدت و کیفیت خواب، و تعداد روزها و زمان هر جلسهٔ تمرین، هر قسمت انتخاب مستقل دارد. انتخاب «سایر» فیلد توضیح را باز می‌کند و نوشتن آن برای ادامه لازم است. دارو، آسیب و مکمل نیز جای توضیحات تکمیلی اختیاری دارند. هر فیلد توضیح تا ۱۰۰۰ حرف می‌پذیرد. پاک‌کردن انتخاب یا جایگزینی «سایر»، متن پنهان آن را هم پاک می‌کند. سؤال‌های بعد از آشنایی همچنان اختیاری هستند.

پاسخ‌ها با قالب `?: سؤال-> پاسخ` مستقیم از مرورگر و با همان تنظیمات `BALE_BOT_TOKEN`، `BALE_CHAT_ID` و `BALE_CHAT_ID2` فرم BMI ارسال می‌شوند. همهٔ گزینه‌های انتخاب‌شده، متن «سایر»، توضیحات تکمیلی و هر دو قسمت سؤال‌های ترکیبی در مرور نهایی و متن ارسالی حضور دارند. پاسخ‌های طولانی در چند پیام مرتب با شناسهٔ مشترک می‌آیند. عکس‌های اختیاری با `sendPhoto` ارسال می‌شوند؛ هر عکس JPG یا PNG و حداکثر ۵ مگابایت است.

همانند فرم BMI، درخواست‌ها `no-cors` هستند؛ پاسخ بله از مرورگر قابل بررسی نیست. صفحه بین پایان درخواست‌ها و تأیید دریافت قطعی تفاوت می‌گذارد و در وضعیت نامشخص خودکار دوباره ارسال نمی‌کند. تنظیمات بله طبق روش موجود در JavaScript خروجی حضور دارند. هیچ‌کدام از آزمون‌ها پیام واقعی به بله نمی‌فرستند.

در Vercel فقط مسیر پرسشنامه اجازهٔ اتصال به بله و پیش‌نمایش `blob:` عکس‌ها را دارد؛ سیاست صفحهٔ اصلی همان مقدار قبلی است.
