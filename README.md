# روکسانا

لندینگ فارسی و راست‌چین با React و Vite. رابط سایت در `src/App.jsx` است. سه وزن ایران‌سنس X از فایل‌های ارائه‌شده در پروژه قرار دارند.

## اجرای محلی

با Node.js نسخه ۲۲٫۱۲ یا بالاتر، پوشه پروژه را باز کن و اجرا کن:

```sh
npm ci
npm run dev
```

آدرس چاپ‌شده در ترمینال را باز کن. این دستور سایت و مسیر محلی `/api/contact` را اجرا می‌کند. برای ارسال واقعی به بله، فایل `.env.example` را به `.env.local` کپی کن و مقادیر معتبر `BALE_BOT_TOKEN`، `BALE_CHAT_ID` و `BALE_CHAT_ID2` را در آن قرار بده. این متغیرها فقط در سمت سرور خوانده می‌شوند و نباید پیشوند `VITE_` داشته باشند. اگر مقدارها تنظیم نشده باشند، فرم به‌جای 404 پاسخ «ارسال به بله هنوز فعال نشده» می‌دهد.

## فعال‌کردن ارسال به بله

1. پروژه را با تنظیمات Vite روی Vercel وارد کن. پوشه اصلی همان پوشه‌ای است که `package.json` و `vercel.json` در آن قرار دارند.
2. در **Settings → Environment Variables**، متغیرهای `BALE_BOT_TOKEN`، `BALE_CHAT_ID` و `BALE_CHAT_ID2` را برای محیط موردنظر تنظیم کن. شناسه‌ها باید عددی و متفاوت باشند. چون توکن قبلی در فایل نمونه قرار گرفته بود، آن را در بازوی پدر بله باطل کن و توکن تازه بگیر. متغیرها نباید پیشوند `VITE_` داشته باشند.
3. پروژه را دوباره Deploy کن. با قد ۱۶۵ و وزن ۸۴٫۵ و اطلاعات تماس نمونه، فرم را امتحان کن و دریافت پیام در چت مقصد را بررسی کن. اگر مقصد چت شخصی است، ابتدا گفت‌وگو با بازو را در بله شروع کن.
4. پیش از انتشار عمومی، برای درخواست‌های POST به `/api/contact` در فایروال هاست محدودیت نرخ بر اساس IP بگذار تا ارسال‌های انبوه کنترل شوند.

تابع `api/contact.js` با درخواست POST و بدنه JSON متد `sendMessage` بله را فراخوانی می‌کند. با زدن دکمه ارسال درخواست، نام، شماره موبایل یا آیدی اینستاگرام، نتیجه اولیه BMI و مشکلات سلامتی انتخاب‌شده به دو مقصد بله فرستاده می‌شوند. قد و وزن فقط برای کنترل دوباره BMI به تابع سایت می‌رسند. فرم تماس برای نتایج معتبر BMI، چه کمتر از ۳۰ و چه ۳۰ یا بالاتر، نمایش داده می‌شود و محدوده نتیجه در پیام بله مشخص است. پروژه دیتابیس ندارد.
