# رکسانا

لندینگ فارسی و راست‌چین با React و Vite. رابط سایت در `src/App.jsx` است. سه وزن ایران‌سنس X از فایل‌های ارائه‌شده در پروژه قرار دارند.

## اجرای محلی

با Node.js نسخه ۲۲٫۱۲ یا بالاتر، پوشه پروژه را باز کن و اجرا کن:

```sh
npm ci
npm run dev
```

آدرس چاپ‌شده در ترمینال را باز کن. برای فعال‌کردن ارسال، مقدارهای معتبر `BALE_BOT_TOKEN`، `BALE_CHAT_ID` و `BALE_CHAT_ID2` را در `.env.local` قرار بده. می‌توانی از `.env.example` به‌عنوان الگو استفاده کنی.

## انتشار روی IIS

1. پیش از ساخت، مقدارهای بله را در `.env.local` یا متغیرهای محیطی سیستم تنظیم کن. شناسه‌های چت باید عددی و متفاوت باشند.
2. اجرا کن:

	```sh
	npm run build
	```

3. محتویات پوشه `dist` را روی IIS قرار بده. با تغییر مقدارهای بله، باید دوباره build و فایل‌های `dist` را جایگزین کنی.

فرم، درخواست‌ها را مستقیماً از مرورگر به بله می‌فرستد و مسیر `/api/contact` را استفاده نمی‌کند. مقدارهای `BALE_*` هنگام build داخل JavaScript عمومی قرار می‌گیرند و برای هر بازدیدکننده قابل مشاهده‌اند. چون درخواست با `no-cors` ارسال می‌شود، مرورگر پاسخ بله را پنهان می‌کند؛ پیام موفقیت در سایت به معنی تأیید قطعی تحویل نیست. اگر چت مقصد شخصی است، ابتدا گفت‌وگو با بازوی بله را شروع کن.
